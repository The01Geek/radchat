Third-party license notices for RadChat

RadChat itself is licensed under the Apache License, Version 2.0 (see

What is redistributed where
---------------------------

- dist/radchat.js (ES module): no third-party code is bundled. React,
  React DOM and all runtime dependencies are imported from the host
  application and installed by its package manager.
- dist/radchat.css and dist/standalone/radchat.css: include the base
  stylesheet of react-chatbot-kit (MIT, Copyright (c) 2020 Fredrik Strand
  Oseberg).
- dist/standalone/radchat.umd.js and demo builds: bundle React, React DOM,
  scheduler and every production dependency listed below.

All of these packages are under permissive licenses (MIT or ISC). The
full license texts follow the package list.
